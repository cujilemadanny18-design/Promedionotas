# restaurante_app

## Descripción

Sistema de administración básica de un restaurante desarrollado en Python utilizando Programación Orientada a Objetos y estructuras de datos.

El proyecto permite administrar productos y usuarios mediante un menú interactivo ejecutado desde consola.
